# Lesson 1 — English Forms (lesson key `1e`)

Five Google Forms, each a copy of the matching Hebrew form, translated.
Copy the text **exactly**: the presentation screen matches answers by
their exact wording, and reads each answer by its column position, so
the question order must stay as written.

All questions are **required**. Form title for all five: **Getting to Campus**.

Answer-type notes:
- "Multiple choice" = one answer only (radio buttons), same as the Hebrew forms.
- "Other" is a **regular option**, not Google's built-in "Other: ___" with a text box.
- Cost and time are "Short answer" (numbers).
